# Шаблон ХИТА (900–1400 знаков)

1. Название конструкции (не тикер)
2. Из каких потоков денег состоит (кто платит кому)
3. Где разность метрик между уровнями (объём → маржа → хвост риска)
4. Типичный тупик розницы
5. Один вопрос читателю про его ограничение (капитал / канал / допуск)
6. Пометка: не рекомендация сделки

Запрещено: купите монету X, плечо, гарантия доходности, обход закона, накачка токена, чужие инсайды как факт.
