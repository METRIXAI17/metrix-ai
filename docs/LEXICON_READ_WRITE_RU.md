# Лексикон: слова для считывания и выдачи ответов

Источник кода: `backend/core/circle_system/lexicon.py`  
API: `GET /api/v1/analytics/lexicon`

---

## Считывание (READ)

### Достоверность

| Класс | Примеры маркеров |
|-------|------------------|
| **ТОЧНО ДА** | точно да, однозначно, подтверждено, уже есть, внедрено, definitely, confirmed, we have |
| **ТОЧНО НЕТ** | точно нет, невозможно, запрещено, отсутствует, не делаем, never, blocked, out of scope |
| **НЕОПРЕДЕЛЕНО** | не знаю, возможно, примерно, зависит, tbd, maybe, unclear, not sure, ? |

### Слои-потребности (circle layers)

identity · orientation · resources · operations · product · pilot · metrics · integration · orchestration · expertise  

Маркеры: бренд/ва, ниша/рынок, бюджет/команда, процесс/sla, продукт/тз, пилот, kpi/vvi, api/crm, оркестр/автопилот, эксперт/deep tech.

### Ресурсы

compute · data · human · capital · channel · ip

## Выдача (WRITE)

### Оболочки тестов (quiz)

- binary: `Тест [{slot}]: … ТОЧНО ДА / ТОЧНО НЕТ / НЕ ОПРЕДЕЛЕНО`
- scale: `0–4`
- choice / numeric / **assembly** (условия сборки, не «тепло»)

### Тепло ответа (только тон)

| Band | Диапазон | Лексемы (RU) |
|------|----------|--------------|
| cold | 0–0.25 | факт:, параметр:, статус: |
| cool | 0.25–0.45 | по данным, следует, рекомендуется |
| neutral | 0.45–0.60 | можно, имеет смысл, практический шаг |
| warm | 0.60–0.80 | давайте, вместе, уже близко |
| hot | 0.80–1.0 | сильный сигнал, готово к пилоту |

**Cap:** если assembly < 0.35 → тепло не выше cool.

### Статусы

`ТОЧНО ДА` · `ТОЧНО НЕТ` · `НЕОПРЕДЕЛЕНО`  
EN: CERTAIN YES / CERTAIN NO / UNDEFINED  
Codes: CY / CN / U

---

## Принцип

1. Анализ неопределённых значений = **сборка**.  
2. Ответы = **лингвистическое тепло**.  
3. Одно не подменяет другое.
