# Производная: менеджмент работы с ИИ

Metrix AI умеет собирать производные. Эта — про посадку ИИ в работу, не про чат.

Store категория 7: размещения в финансовых потоках.

## Промпт (вставить в агента)

См. `backend/core/ai_mgmt.py` → `PROMPT`.

## Артефакты ценности

1. Work Charter — работа, unit, молчание, kill. Одна страница.
2. Kill Card — факт, который заканчивает прогон.
3. Placement Seat — стул агента в чужом денежном потоке.
4. Proof Packet — объект, который человек показывает без тебя.

ИИ без стула в деньгах — хобби.
