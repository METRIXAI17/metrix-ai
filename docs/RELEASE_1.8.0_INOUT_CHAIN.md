## $5 — нет

После Tribute 10% с $5 остаётся $4.50. Railway Hobby — это пол $5, не потолок. Второй сервис (отдельный рендер Tape Land) — ещё $5–12. $5-подписка финансирует хостинг в ноль и не оплачивает обновления моделей.

Hobby $5 **как тариф Railway** хватает на текущий один FastAPI+бот при низком трафике (~0.15 vCPU / 0.4 GB). Обновления — git push, не отдельный сервис. Когда появится 20+ Access — Pro $20 и только тогда думать о втором рендере.

## 152-ФЗ / локализация. Пошагово

1. **Не собирать анкету.** Нет email, телефона, ФИО, паспорта в продукте.
2. **Tribute — merchant of record.** Платёжные ПДн остаются у Tribute (у них контур под РФ-карты / Stars).
3. **На Railway писать только HMAC.** `subject_hash = HMAC-SHA256(secret, telegram_user_id)`. Сырой id не пишется. Токен показывается один раз, в файле — hash.
4. **Сессии бота** — файл назван HMAC, не chat_id.
5. **Webhook Tribute** → `POST /api/v1/miniapp/tribute/webhook` с `trbt-signature`. Env: `TRIBUTE_API_KEY`, `TRIBUTE_ACCESS_URL`, `METRIX_TOKEN_SECRET`.
6. **Не логировать initData, имена, телефоны.**
7. Когда/если понадобится хранить настоящие ПДн резидентов РФ — отдельный контур на RU-хосте (Selectel/Yandex Cloud). Сейчас не нужно: доступа достаточно.
8. Публичные формулировки: «код согласованной модели», не «сигналы», не «рекомендации».

Это минимизация ПДн, не обход закона. Если начнёте хранить ФИО/телефон — HMAC уже не спасёт.
