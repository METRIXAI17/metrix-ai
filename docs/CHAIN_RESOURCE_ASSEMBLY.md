# Resource Assembly — first act of chain

Chain does not start from client text. Chain starts when resources bind to empty constructor-form slots (`outcome_frame`, `void_membrane`, `revenue_hinge`, zonal Infra/Cloud/Structure/Product). **No bind → no `chain_id`.** This is slot fill, not a zip archive.

## Compatibility (feeds pilot `k`, `y0`, L = 0.92)

```
compat = 0.45 · (critical_bound / 4)
       + 0.25 · mean(primary confidence)
       + 0.15 · (1 − deadlock_risk)
       + 0.15 · load_balance
```

Deadlock and load come from Market Units coordination. Contested artefacts have confidence 0 and do not raise assembly. Unbound critical slots force CY/CN/U = U; warmth names what is not assembled.

`void_delta` > 0 when critical slots close (VVI falls). `void_delta` < 0 when they stay empty (VVI rises). Pilot logistic still uses predetermined **L = 0.92**.

API: `POST /api/v1/analytics/chain/resources/bind` · `GET /api/v1/analytics/chain/{chain_id}`.
