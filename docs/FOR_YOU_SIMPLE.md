# Простыми словами: что продаём, как платят, какие ключи

## Три разных товара (не путать)

1. **Бот Karim Metrix** — ленд (вход). Человек открывает Telegram и получает **результат** (карту).  
   Разовая посадка бота: от **$490**, не дороже **$1990**. Это не Metrix AI.

2. **Подписка Access 3 290 ₽ / месяц** — доступ в бота.  
   Сначала **2 бесплатных результата**. Потом оплата. В месяце **40 результатов**.

3. **Metrix AI $2490** — главный движок.  
   Собирает: операционные процессы + оригинальный проект + продвижение.  
   Это не подписка бота. Это пакет работы движка.

---

## Что такое «прогон» и как говорим теперь

Раньше в коде это называлось прогон = один запуск сборки.  
Для человека говорим **результат** (одна карта в боте).

- Бесплатно: **2 результата**, потом стена.  
- Access 3290: **40 результатов в календарный месяц**, потом «лимит месяца».  
- Metrix AI $2490: **один пакет** (не 40 запусков API).

---

## Сколько это стоит тебе (себестоимость)

Бот **не вызывает платную внешнюю LLM** на каждый результат. Считается на Railway.

| Что | Тебе примерно | Клиенту |
|---|---|---|
| 1 результат в боте | **< 1 ₽** (доли цента на CPU) | 2 бесплатно, потом из 3290 |
| 40 результатов / месяц | **< 40 ₽** compute | 3 290 ₽ Access |
| 1 полный Metrix AI (`POST /process` + пакет) | **рубли на сервер + твоё время 1–2 недели** | **$2490** |

Маржа Access: Tribute −10% → ~2 961 ₽. Сервер ~$5–11. Остальное — развитие.

Если позже подключишь платную модель (Grok и т.п.) — себестоимость результата вырастет. Сейчас нет.

## Как платит и пользуется человек

1. Пишет боту / открывает Mini App.  
2. Получает **2 бесплатных результата**.  
3. На третий — стена: «Access 3 290 ₽, 40 результатов». Кнопка Tribute.  
4. Платит в Tribute (карта / СБП / как даст Tribute). Tribute — касса, не ты.  
5. Tribute пишет нашему серверу «оплачено». Бот открывает Access. Имя/телефон мы не копим.  
6. Пользуется ботом до 40 результатов в этом месяце.  
7. Если нужен полный движок (ops + проект + промо) — это **отдельный счёт $2490**, не кнопка Access.

**Ты видишь:** кабинет Tribute (деньги 10 и 25 числа, комиссия 10%). В боте — факт доступа, не паспорт.

## Куда спрятать копию, чтобы не украли и не удалили

**Supabase — не для кода.** Он для данных (логи, доступы). Если удалят GitHub, Supabase код не спасёт.

Надёжно:

1. **GitHub** (уже есть `METRIXAI17/metrix-ai`) — сделай репозиторий **Private**, если ещё Public.  
2. **Второй git** — GitLab.com или Gitea: `git remote add backup https://gitlab.com/...` и `git push backup main`.  
3. **Раз в неделю zip** папки `Desktop/metrix-ai` на диск / флешку (без `.env`).  
4. **Supabase** — да, как копия *данных* (кто оплатил Access). SQL уже в `docs/SUPABASE_FULL_SCHEMA.sql`. Не секретный код.

Итог: код = два git + zip. Данные оплат = Tribute + опционально Supabase. Railway сам по себе бэкапом не является.

## Ключи в Railway — откуда взять (по одному)

Railway → твой сервис `metrix-ai` → **Variables** → New variable.

| Имя | Что это | Откуда взять |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Пароль бота | Telegram → **@BotFather** → твой бот → API Token. Уже может стоять. |
| `TELEGRAM_WEBAPP_URL` | Ссылка Mini App | `https://metrix-ai.vercel.app/tg/` |
| `METRIX_PUBLIC_URL` | Адрес API | `https://metrix-ai-production.up.railway.app` |
| `METRIX_TOKEN_SECRET` | Секрет для HMAC (не пароль Tribute) | Сам придумай длинную строку. В PowerShell: `[guid]::NewGuid().ToString("N")+[guid]::NewGuid().ToString("N")`. Вставь как есть. Никому не отправляй. |
| `TRIBUTE_API_KEY` | Ключ Tribute | Telegram → бот **Tribute** → кабинет автора → ⋯ Settings → API Keys → Generate. |
| `TRIBUTE_ACCESS_URL` | Ссылка на товар 3290 ₽ | В Tribute создай продукт «Metrix Access» 3290 ₽ / месяц. Скопируй ссылку на оплату. |
| `TRIBUTE_CUSTOM_URL` | Ссылка Custom $500 | По желанию, второй продукт Tribute. |
| `METRIX_FREE_RUNS` | Сколько бесплатных результатов | `2` (можно не ставить — уже 2). |
| `METRIX_ACCESS_RUNS` | Лимит Access в месяц | `40` (можно не ставить). |

**Webhook Tribute** (в том же Settings Tribute, поле Webhook URL):

`https://metrix-ai-production.up.railway.app/api/v1/miniapp/tribute/webhook`

После сохранения Variables Railway сам перезапустит сервис.

Проверка: открой в браузере  
`https://metrix-ai-production.up.railway.app/api/v1/analytics/sales-readiness`  
Там `tribute_url` и `token_secret` должны стать true, когда переменные стоят.
