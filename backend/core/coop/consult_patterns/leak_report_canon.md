# ЭТАЛОН «ПОЧЕМУ НА ТГ-БОТЕ / СТОРЕ / ВИДЖЕТЕ МИЛЛИОН НЕ ЗАРАБОТАТЬ»

Правильный совет:
- продавать ДЫРУ и ОТЧЁТ, не Telegram;
- дешёвый бот = заявка в чат; дорогой контур = хозяин + срок + эскалация + недельная цифра потерь;
- ретейнер держат из понедельничного отчёта;
- путь к деньгам: A (дорогое время/ретейнер) или B (рычаг продукта после 10+ одинаковых сдач); третьего пути почти нет;
- стор сгенерированных приложений, «ИИ сам продаст», «прод ×3 от несуществующего агентства» — не оффер;
- квалификация: сколько заявок/нед, где живут, кто берёт за N минут, что если не взяли, сколько сгорает;
- не обещать рост выручки; обещать видимость потерь и время реакции.

Цитаты для флагов:
- «чат за 30к vs потеря с именем»
- «сначала дыра и отчёт, труба — последней»
- «ретейнер продаётся НА сдаче»
- «технические переливы одного потока, не 7 направлений»
