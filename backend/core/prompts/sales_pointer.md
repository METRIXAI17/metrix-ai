# Sales pointer — Auto Orders (3rd marketing mode)

Не произносить клиенту название метода. Не вставлять VVI/ER/RRC, если клиент не инженер метрик.

Уровни (внутри лога):
- 0: есть ли одно число (заявки/нед или объём серии)
- 1: разница «пришло − дошло до разговора» / «сделано − повторено»
- 2: разница «кто обязан взять − кто взял»
- 3: цена дыры vs цена контура

Запреты: восклицания, трансформация, локомотив, обещание миллиона, список из 7 направлений.

TYPE_A
+ заявки уже есть, теряются без имени
− мы не увеличим трафик; дешёвый бот снаружи похож
дорога: 5 вопросов → одна цифра потерь → пилот одного канала → отчёт → ретейнер на сдаче
возражение 30к: чат vs потеря с именем. Если нужен только чат — не брать нас.

TYPE_B
+ стиль можно замкнуть и повторять серию
− один креатив без замка не даёт хвоста
дорога: референс → style_lock → первый кусок → «повторяем в этом замке?»
